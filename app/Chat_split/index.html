Start a conversation

Load a data file by typing "load data url [URL]" in the chat or load a map project (JSON) or a map present in a HTML page via 'Load Map'.

After data or map are loaded you can ask questions about your data, explore features, and get insights, change visualization properties.

Try:
• Show sample data
• "load data url https://example.com/data.csv"
• "What data is available?"
• "Show me all features" (displays all data on the map)
• "Find countries with population over 1000000"

Map assistant

This chat is connected to the map on this page. You can ask about loaded themes and data, change how values are shown (for example color by …), set tooltips or filters, or explore the data in plain language.

Try:
• What themes are on the map?
• "Color by population"
• "What data is available?"
• "load data url …" to add another dataset
